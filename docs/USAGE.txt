================================================================

 闰土微信记录导出器  ·  使用说明
================================================================

【一、启动】
  双击「闰土微信记录导出器.exe」
    首次启动会先弹出「连接微信数据」页面 → 选好账号目录 → 连接并进入
    勾选「记住此目录」后，下次直接进入主界面；顶栏「目录设置」可随时切换
    全程原生窗口，不依赖浏览器

  命令行：
    闰土微信记录导出器.exe                      正常启动
    闰土微信记录导出器.exe --files-only          只看已导出目录
    闰土微信记录导出器.exe --export-dir "D:/导出" 指定默认导出目录
    闰土微信记录导出器.exe --account "E:/.../wxid_xxx" 指定账号目录

【二、连接微信数据（启动页 / 目录设置）】
  · 上方自动列出本机检测到的账号：数据库数量、最后消息时间、「当前使用中」标记
  · 点选候选即可；也可以「浏览…」或直接粘贴路径
  · 支持 xwechat_files 根目录 / wxid_xxx_xxxx 账号目录 / db_storage，自动归一化
  · 校验通过显示「✓ 已识别账号目录（N 个数据库），可以进入主界面」
  · 「记住此目录」勾选后不再弹窗；取消勾选则每次启动都询问

【三、设置（顶栏「设置」）】
  · 工作空间：导出默认目录，默认 <应用目录>\workspace
  · 日志：可开关、指定目录（默认 <应用目录>\logs）、保留天数（默认 30）、级别
  · 保存后在应用目录生成 config.ini（含 [general] 与 [logging] 两段）
  · 「打开日志目录」可直接定位 app.log（按天滚动，超期自动删除）

【四、界面】
  左侧
    · 全部会话（群聊 + 单聊），按最近消息排序
    · 真实好友头像（head_image.db，本地已缓存）
    · 搜索 + 全部 / 群聊 / 单聊 筛选（列表虚拟化，输入即时响应）

  右侧
    · 会话标题、群聊/单聊标签、时间范围、消息与图片统计
    · 「全部类型」筛选：文本 / 图片 / 文件 / 链接 / 语音 / 表情 / 视频 / 系统消息
    · 「在会话内搜索」关键词过滤
    · 聊天区：蓝色气泡=我、灰色=对方；群聊显示发言人；顶部「加载更早的消息」
    · 图片页：日期排序缩略图墙，双击看大图（← → 翻页、Esc 关闭、可另存为）

【四、导出（时间范围 / 目录结构）】
  点「导出图片」「导出记录」或「一键导出全部」后：
    1) 先弹出导出选项
       · 时间范围：全部时间 / 最近 7 天 / 最近 30 天 / 最近 3 个月 / 最近 1 年 /
                   自定义…（选起止日期）
       · 导出内容：聊天记录（txt / html / json）、图片、文件（文档/压缩包等），可任意组合
       · 图片目录结构：
           - 按日期分层：图片/2026/11/16/171230_abcd1234.jpg；文件/2026/11/16/xxx.pdf
           - 平铺同目录：图片/20261116_171230_abcd1234.jpg；文件/xxx.pdf
    2) 再选择导出目录（默认上次使用的目录）
    3) 后台导出，底部实时进度条 + 取消，界面不卡

  一键导出全部：导出所有会话记录（可选含图片），完成后打包为
    导出目录\微信全部导出_日期_时间.zip
  含图片时体积可能几十 GB，请留意磁盘空间。

【五、性能说明（本版优化）】
  会话列表刷新：2~6 ms（原 2400 ms）
  点击会话：1~2 ms 内响应，聊天内容后台解析后自动填充
  二次打开同一会话：约 100 ms 内
  会话内搜索 / 类型筛选：5~40 ms
  首次打开几万条的大群需要 0.5~1 秒解析，期间显示「正在加载」提示，不会卡住界面。

【六、数据与隐私】
  · 只读微信 4.x 本机数据库，不修改任何数据
  · 图片与头像按需解密，缓存到 %LOCALAPPDATA%\wx4export\img\
  · 配置保存在 %LOCALAPPDATA%\wx4app\config.json
  · 全程本地运行，不联网、不上传

【七、常见问题】
  Q 首次启动慢？
    需要从微信进程内存取数据库密钥（10~40 秒），密钥会缓存。
  Q 提示找不到数据库？
    确认微信已登录；或用「目录设置」重新选择账号目录。
  Q 会话比手机上少？
    只显示本地库里有消息的会话。
  Q 头像不显示？
    该好友在 head_image.db 里没有缓存头像，会用首字彩色头像代替。
  Q 只想导出某段时间？
    导出选项里选「最近 30 天」等预设，或选「自定义…」指定起止日期。
  Q 图片想全部放一个文件夹？
    导出选项 → 图片目录结构 → 选「平铺到同一目录」。

【九、本版新增（V2.3）】
  1) 导出的 聊天记录.html 已带真实头像与内嵌图片
     · 头像来自 head_image.db，以 base64 内嵌（同一人只嵌一次，577 条记录 HTML 约 99 KB）
     · 勾选"图片"导出时，HTML 里的图片会直接内联显示（相对路径 图片/…）
     · 语音消息显示为「🔊 语音 12″」卡片
     说明：微信 4.x 的语音音频默认不落盘（只在 CDN + 数据库里存 aeskey），
           本机实测 msg/attach 下没有 Audio 目录与 .aud/.silk 文件，
           因此暂时只能显示时长、无法播放；若某天微信把语音缓存到本地，可再接上播放。

  2) 窗口改为无边框圆角（含所有二级弹窗）
     · 顶部标题栏可拖动，双击可最大化/还原，右上角 — □ ✕
     · 右下角可拖拽调整窗口大小
     · 弹窗同样圆角、可拖动，只保留关闭按钮

  3) 文件导出（与图片同逻辑）
     · 识别聊天里的文件消息（XML: title + totallen），到 msg/file/年-月/ 匹配本地副本
     · 支持时间范围、平铺 / 按日期分层，导出到 <会话>/文件/…
     · HTML 里显示为文件卡片（📄 文件名 + 大小 + 点击下载）
     · 说明：微信只在电脑端下载过的文件才会留在本地，未下载的会标为「未随记录导出」；
             实测 672 个文件消息中约 543 个能找到本地文件（其余为本地缺失）

5) 修复：聊天窗口里的头像
     · 之前用「昵称」去头像库查，查不到就退回首字；现在按 wxid（_uid）查，
       群聊成员、自己的头像都能正确显示
     · 少数联系人 head_image.db 里没有缓存头像，仍会用首字彩色头像代替

  4) 导出完成后弹窗提示「打开目录 / 关闭」
     点「打开目录」直接在资源管理器打开导出位置。
